Executo
Solo · self-correcting code agent
A self-correcting Python code-generation agent using LangGraph and Llama 3.1 8B (via Groq) — generates code and unit tests from plain-English prompts, executes them in an isolated Docker sandbox (no network, capped CPU/RAM), and iterates up to 4 attempts until both AI-generated and HumanEval tests pass. Achieved an 80% strict pass rate on a 30-task HumanEval sample (~1.5 attempts per solved task).
Python LangGraph Llama 3.1 8B Docker HumanEval
